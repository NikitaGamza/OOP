# Приложение онлайн продаж

Приложение содержит: 
- Классификацию товаров.
- Классификацию категорий
- Разделение товаров на классы (наследуются от родителя)

Все вышеперечисленные классы определяются через абстрактный базовый класс 
и его методы. В приложении созданы миксины для более гибкой настройки 
новой функциональности с использованием множественного наследия.

Приложение позволяет добавлять товары; устанавливать и получать цену через 
сеттер и геттер (выставлены ограничения, чтобы цена не была 0 или ниже); 
получать список товаров; получать детальные характеристики о товаре; добавление товара в 
нужную категорию; получать общую сумму всех выбранных товаров; подсчитывать среднюю цену 
товаров в категориях

В приложение введены обработчики ошибок для исключения добавления товаров с нулевым количеством;
исключено деление на ноль при попытке подсчёта средней цены товара
